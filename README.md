# Gwent Mobile (fan project)

Projeto Android experimental para jogar uma versão inspirada no minigame de cartas de The Witcher 3.

## Compilar APK sem PC

O GitHub Actions compila o aplicativo em um runner Ubuntu. Abra **Actions**, execute **Build Android APK** e baixe o artefato `GwentMobile-debug-apk` ao final.

## Observação

Projeto de fã, não oficial e sem vínculo com CD PROJEKT RED. Marcas, personagens e conteúdos originais pertencem aos respectivos titulares.
