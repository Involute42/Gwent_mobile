# Build the Android APK

1. Open the repository's **Actions** tab.
2. Select **Build Android APK**.
3. Tap **Run workflow** on the `main` branch (or wait for the push-triggered build).
4. Open the completed run and download `GwentMobile-debug-apk` from **Artifacts**.

The artifact contains `app-debug.apk`. This is a debug-signed build for testing, not a Play Store release package.
